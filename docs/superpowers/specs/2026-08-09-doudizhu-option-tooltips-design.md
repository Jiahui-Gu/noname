# 斗地主选项悬停说明设计

## 目标

为斗地主设置中的“加强地主”“农民遗产”和“〖飞扬〗版本”下拉项增加鼠标悬停说明。说明始终可见，不受“鼠标悬停显示信息”总开关影响，并同时覆盖单机与联机设置。

## 方案

保持实现最小化，不新增弹层组件，也不修改通用菜单框架。复用配置项已有的 `textMenu` 钩子，在下拉选项对应的 DOM 节点上设置原生 `title` 属性。

在 `apps/core/noname/library/index.js` 中定义一个斗地主选项说明绑定函数，并由上述三组单机、联机配置共同引用：

- “加强地主”按选项 key 读取现有技能的 `<skill>_info` 翻译；“禁用”不显示说明。
- “〖飞扬〗版本”将 `online`、`mobile`、`decade` 分别映射到 `feiyang`、`mbfeiyang`、`dcfeiyang`，再读取对应的 `_info` 翻译。
- “农民遗产”按 `dieAfter2` 的现有逻辑提供固定说明：OL 版本摸一张牌，手杀版本摸两张牌或回复一点体力，十周年版本无遗产效果。

这样可以直接复用技能翻译和菜单扩展点，避免复制技能描述或引入新的 UI 行为。

## 边界与错误处理

说明函数只处理这三类已知配置。未知选项或没有说明的选项不设置 `title`，不会显示空提示，也不会影响选项点击和配置保存。

## 验证

增加或调整现有测试，验证：

- 六处单机、联机配置都使用同一说明绑定函数。
- 三类选项 key 映射到正确说明。
- “禁用”和未知 key 不产生说明。
